# 삼삼엠투 숙박정보 크롤러

삼삼엠투(33m²) 웹사이트 검색 페이지에서 숙박 정보를 **동적 크롤링**으로 수집하는 GUI 프로그램입니다.  
PyQt5 + Selenium으로 구현되었으며, 엑셀 저장 시 **대표이미지는 제외**하고 텍스트 정보만 저장합니다.

---

## 주요 기능

- **삼삼엠투 검색 페이지 자동 접속**  
  `https://web.33m2.co.kr/guest/search` 기준
- **수집 개수 설정**  
  - **숫자 직접 입력**: 1~500개 (스핀박스)
  - **빠른 선택**: 10, 20, 50, 100, 200, 500개
- **실시간 진행률** 및 **로그** 표시
- **엑셀(xlsx) 저장**  
  컬럼 순서·이름 고정, 대표이미지·이미지목록 미포함
- **봇 감지 우회**  
  User-Agent·자동화 속성 제어

---

## 수집 데이터 (엑셀 저장 항목)

엑셀에는 아래 9개 컬럼만 저장됩니다 (왼쪽부터 순서 고정).

| 순서 | 컬럼명   | 설명           |
|------|----------|----------------|
| 1    | Index    | 순번           |
| 2    | 숙소명   | 숙소 제목(h3)  |
| 3    | 위치     | 세부 위치/특징 |
| 4    | 가격     | 주요 가격(원/기간) |
| 5    | 가격상세 | 임대료/관리비  |
| 6    | 방구성   | 방·화장실·주방 등 |
| 7    | 상세링크 | /guest/room/ID |
| 8    | 숙소ID   | room ID        |
| 9    | 할인정보 | 장기계약·즉시입주 할인 등 |

- **대표이미지·이미지목록**은 저장하지 않습니다.

## 33m² 사이트 HTML 구조 (선택자 기준)

크롤러는 아래 구조를 기준으로 동작합니다.

- **목록 컨테이너**: `ul[class*="grid"]` 내부 `li.h-fit` (카드 단위)
- **카드 내부**: `<a href="/guest/room/ID">` 안에
  - **숙소명**: `h3.typo-body1`, `h3.font-semibold.text-gray-900`
  - **위치/특징**: `p.typo-label1` (예: 공덕/광화문/여의도)
  - **방구성**: `div.typo-label1.flex.gap-2.font-normal.text-gray-500`
  - **가격**: `strong.typo-headline3` 또는 부모 `p.flex.items-center.gap-0.5.font-bold`
  - **가격상세**: `div.typo-label1.mb-2.flex.gap-2`
  - **할인**: `div.bg-gray-50.rounded-sm`
- **추가 로드**: 목록 영역 `ul.overflow-y-auto` 스크롤 또는 창 스크롤

선택자·딜레이 등은 `src/config.py`의 `SELECTORS`, `DELAY_*`, `SCROLL_DELAY_*`에서 조정할 수 있습니다.

## 설치 및 실행

### 1. 저장소/폴더로 이동

```bash
cd 33m2-crawler
```

### 2. 가상환경 생성 및 활성화

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python -m venv venv
source venv/bin/activate
```

### 3. 패키지 설치

```bash
pip install -r requirements.txt
```

### 4. 프로그램 실행

```bash
python main.py
```

## EXE 빌드 및 실행

### 빌드 (Windows)

- **CMD**: 프로젝트 루트에서 `build.bat` 실행  
- **PowerShell**:  
  `.\venv\Scripts\pyinstaller.exe build.spec --noconfirm`

빌드가 끝나면 `dist\33m2크롤러.exe`가 생성됩니다. (실행 파일은 나중에 만들 경우 위 순서로 빌드하면 됩니다.)

### EXE 실행 (사용자)

1. `33m2크롤러.exe` 더블클릭
2. 최초 실행 시 Chrome/ChromeDriver 관련 설치가 필요할 수 있음
3. GUI가 뜨면 아래 사용 방법대로 진행

---

## 사용 방법

### 1단계: 홈페이지 접속

- **[홈페이지 접속]** 클릭  
- Chrome이 열리고 삼삼엠투 검색 페이지로 이동  
- “접속 완료” 안내 후 **[크롤링 시작]** 활성화

### 2단계: 수집 개수 설정

- **스핀박스**: 1~500 사이 숫자 직접 입력
- **빠른 선택** 드롭다운: 10/20/50/100/200/500개 선택 시 스핀박스 값 자동 반영  
- 실제 수집 개수는 **스핀박스에 표시된 값**으로 적용

### 3단계: 크롤링 시작

- **[크롤링 시작]** 클릭 후 확인
- **진행 상황**: 진행률 바, N/목표 개수 표시
- **로그**: 타임스탬프·[INFO]·수집 항목명 등 출력  
  - 세로 스크롤바 항상 표시, 새 로그 추가 시 자동으로 맨 아래로 스크롤
- 중단 시 **[중단]** 클릭 (이미 수집된 데이터는 유지)

### 4단계: 엑셀로 저장

- 크롤링 완료 후 **[엑셀로 저장]** 활성화
- 저장 위치·파일명 선택 (기본: `33m2_숙소목록_YYYYMMDD_HHMMSS.xlsx`)
- 위 “수집 데이터” 항목의 9개 컬럼만 저장됨

### 기타

- **로그 지우기**: 하단 중앙 **[로그 지우기]** 로 로그 창만 비우기
- **프로그램 종료**: **[프로그램 종료]** 또는 창 닫기 (크롤링 중이면 확인 후 종료)

## GUI 구성

- **크롤링 설정**: 홈페이지 접속, 크롤링 시작, 중단, 수집 개수(스핀박스 + 빠른 선택)
- **진행 상황**: 상태 문구, 진행률 바, 현재/목표 개수
- **로그**: 읽기 전용 텍스트, 세로 스크롤바 항상 표시, 높이 제한으로 스크롤바가 하단 버튼에 가리지 않도록 구성
- **하단 버튼**: 왼쪽 [엑셀로 저장], 가운데 [로그 지우기], 오른쪽 [프로그램 종료]

수집 결과는 **화면 테이블로는 표시하지 않고**, 로그와 엑셀 저장으로만 확인합니다.

## 설정 요약 (config.py)

- **URL**: `BASE_URL`, `SEARCH_URL`
- **딜레이**: `DELAY_MIN/MAX`, `SCROLL_DELAY_MIN/MAX`, `PAGE_LOAD_TIMEOUT` (속도·안정성 조절)
- **창**: `WINDOW_WIDTH`, `WINDOW_HEIGHT` (기본 800×650, 로그 스크롤바 가림 방지)
- **크롤링 개수**: `DEFAULT_CRAWL_COUNT`, `MAX_CRAWL_COUNT`, `CRAWL_COUNT_OPTIONS`
- **선택자**: `SELECTORS`, `DETAIL_SELECTORS` (사이트 구조 변경 시 수정)

## 주의사항 및 법적 고지

- **개인 학습·연구 목적**으로만 사용할 것.
- 과도한 요청은 서버에 부담을 줄 수 있으니 수집 개수·빈도를 적절히 조절할 것.
- 수집 데이터의 **상업적 이용·재배포**는 하지 말 것.
- 해당 웹사이트의 이용약관 및 robots.txt를 준수할 것.
- 개인정보가 포함된 데이터는 수집하지 말 것.

## 문제 해결 (FAQ)

**Q: 브라우저가 안 떠요**  
- Chrome 설치 여부, 인터넷 연결, 방화벽/백신 차단 여부 확인.

**Q: 크롤링 중 오류가 나요**  
- 33m² 사이트 HTML/클래스 변경 가능성. `src/config.py`의 `SELECTORS`를 개발자 도구로 확인해 수정.

**Q: 엑셀이 저장되지 않아요**  
- 저장 경로 쓰기 권한, 파일명 특수문자 여부 확인.

**Q: 로그 스크롤이 안 보이거나 가려져요**  
- 창 크기를 키우거나, `config.py`의 `WINDOW_HEIGHT`와 `main_window.py`의 로그 영역 `setMaximumHeight`를 필요 시 조정.
